
# Smart Question Paper Generator

## Project Overview

Smart Question Paper Generator is a team-based academic project designed to simplify the process of creating question papers from question banks.

The system aims to help educators organize questions and generate question papers based on academic requirements.

## Key Features

- Question bank management
- Question paper generation
- Organization of questions by modules
- Support for different question formats
- User-friendly frontend and backend structure
